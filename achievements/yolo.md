# 🤙 YOLO

> "You Only Merge Once" — Merge sebuah pull request **tanpa review**, **tanpa passing checks** sebagai syarat, dan langsung ke branch utama.

| Atribut | Nilai |
|:---|:---|
| **Status** | ✅ Unlocked |
| **Tier** | Default (satu kali, tidak bertingkat) |

## Cara Dapat

1. Buka PR dari branch ke `main` di repo yang kamu kontrol.
2. Jangan minta/tunggu review siapa pun.
3. Klik **Merge pull request**.
4. Badge menyusul dalam prosesing GitHub.

## Catatan

- Branch protection rules yang mewajibkan review akan menggagalkan syarat ini.
- Justru badge ini "peringatan" supaya gak nge-merge serampangan — tapi kolektor tetap memburunya.
