# 🌟 Starstruck

> Memiliki sebuah repository yang mendapatkan **bintang dari pengguna GitHub lain**.

| Atribut | Nilai |
|:---|:---|
| **Status** | 🔒 Locked (butuh 16 bintang asli) |
| **Tier saat ini** | Target Default |

## Syarat per Tier

| Tier | Jumlah bintang |
|:---:|:---:|
| Default | 16 |
| Bronze | 128 |
| Silver | 512 |
| Gold | 4.096 |

## Kenapa Nggak Bisa Instan?

- **Self-star tidak dihitung.** GitHub mendeteksi bintang dari pemilik repo.
- Bintang palsu / bot bisa kena flag dan malah dihapus.

## Cara Realistis

1. Bikin proyek yang **memecahkan masalah nyata** (tools, template, library).
2. Tulis README yang jelas dengan: deskripsi, cara install, contoh penggunaan, screenshot.
3. Share ke komunitas:
   - Reddit (r/programming, r/webdev, r/python, dll sesuai topik)
   - Discord/Slack komunitas
   - Twitter/X / LinkedIn / dev.to
4. Maintain proyeknya — balas issue, terima PR kontributor.
