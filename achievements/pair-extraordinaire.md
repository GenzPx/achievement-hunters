# 🤝 Pair Extraordinaire

> Commit yang memiliki **co-author** (lewat trailer `Co-authored-by:`) ikut ter-merge dalam sebuah pull request.

| Atribut | Nilai |
|:---|:---|
| **Status** | 🔄 Pending — perlu co-author dengan email tertaut akun GitHub valid |
| **Tier saat ini** | Target Default |

## Syarat per Tier

| Tier | Jumlah co-authored merged PR |
|:---:|:---:|
| Default | 1 |
| Bronze | 10 |
| Silver | 24 |
| Gold | 48 |

## Format Co-author

Tambahkan trailer ini di **bawah** body commit:

```
Co-authored-by: Nama <email@tertaut-di-github.com>
```

Syarat email co-author **harus terasosiasi dengan akun GitHub** yang valid agar kehitung.

> ⚠️ Cara paling pasti: ajak temen beneran untuk pair commit bareng, karena beberapa sumber menyebutkan co-authored commit idealnya berasal dari **dua kontributor berbeda** yang berkolaborasi.

## Cara Aman Dapetin

1. Kerjain bareng temen satu repo.
2. Salah satu nulis kode, yang lain kasih saran perubahan.
3. Commit dengan `Co-authored-by:` kedua pihak.
4. Buka PR & merge.
