# ⚡ Quickdraw

> "Gitty up!" — Tutup sebuah issue atau pull request dalam **5 menit** setelah dibuka.

| Atribut | Nilai |
|:---|:---|
| **Status** | ✅ Unlocked |
| **Tier** | Default (satu kali, tidak bertingkat) |
| **Tanggal didapat** | Sebelum repo ini dibuat |

## Cara Dapat

1. Buka issue/PR di repo manapun (termasuk repo sendiri).
2. Tutup (close) dalam waktu ≤ 5 menit.
3. Selesai. Tidak ada tier lanjutan.

## Tips

- Paling gampang dilakuin di repo pribadi: buka issue "test", langsung tutup.
- Waktu dihitung dari `created_at` ke `closed_at`.
