# 🦈 Pull Shark

> Buka pull request yang kemudian **di-merge**. Termasuk di repo sendiri.

| Atribut | Nilai |
|:---|:---|
| **Status** | 🔄 Pending verifikasi (menunggu prosesing GitHub ≤24 jam) |
| **Tier saat ini** | Target Default |

## Syarat per Tier

| Tier | Jumlah PR ter-merge |
|:---:|:---:|
| Default | 2 |
| Bronze | 16 |
| Silver | 128 |
| Gold | 1.024 |

## Tips

- Kontribusi ke proyek open-source lain (fix typo, dokumentasi, bug kecil) paling cepat.
- Label `good first issue` adalah temanmu.
- Repo sendiri tetap dihitung, asalkan lewat mekanisme PR (bukan langsung push).
