# 🏆 Achievement Hunters

> Dokumentasi perjalanan memburu **GitHub Achievements** — lencana yang muncul di profil setiap kali kita menyelesaikan milestone tertentu di GitHub.

Repo ini berisi catatan, eksperimen, dan bukti dari tiap achievement yang berhasil (atau sedang diusahakan) untuk di-unlock. Setiap achievement punya halamannya sendiri di folder [`achievements/`](./achievements) beserta penjelasan cara mendapatkannya.

---

## 📊 Progress

| Badge | Achievement | Tier | Status | Cara Dapat |
|:---:|:---|:---:|:---:|:---|
| ⚡ | **Quickdraw** | Default | ✅ Unlocked | Menutup issue/PR dalam 5 menit setelah dibuka |
| 🤙 | **YOLO** | Default | ✅ Unlocked | Merge PR tanpa review sama sekali |
| 🦈 | **Pull Shark** | Default | 🔄 Pending | Memiliki 2 PR yang di-merge |
| 🤝 | **Pair Extraordinaire** | Default | 🔄 Pending | 1 commit co-authored pada PR yang di-merge |
| 🌟 | **Starstruck** | Default | 🔒 Locked | Memiliki repo dengan 16+ bintang asli |
| 🧠 | **Galaxy Brain** | Default | 🔒 Locked | 2 jawaban di Discussions ditandai sebagai jawaban |

> ⏳ Achievement yang baru terpenuhi bisa butuh **hingga 24 jam** untuk muncul di profil. Cek di menu **Profile → Achievements**.

Detail lengkap & cara verifikasi ada di folder [`achievements/`](./achievements).

## 🚀 Cara Kerja (versi singkat)

Setiap lencana punya syarat spesifik yang dipantau otomatis oleh GitHub:

1. **Buka aksi** yang sesuai (mis. buat PR untuk *Pull Shark*).
2. **Penuhi syarat** (PR di-merge, bintang terkumpul, jawaban diterima).
3. **Tunggu prosesing** GitHub — biasanya menit, tapi bisa sampai 24 jam.
4. Lencana muncul di **profil → Achievements**.

> 💡 Mau lihat lencana yang terkunci beserta petunjuknya? Buka profil GitHub kamu dan klik **Achievements**.
